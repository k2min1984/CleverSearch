# 신규 업로드 시험 문서 내용

아래는 Word 시험 파일의 한글 본문입니다. 웹 업로드에는 이 MD가 아니라 같은 이름의 DOCX 파일을 선택합니다.

수동검증 신규문서

감나무다람쥐20261001

이 문서는 2026년 10월 1일 웹 업로드와 검색 확인용 테스트 자료입니다.

회사 업무 자료가 아니며, 테스트가 끝나면 이 문서만 삭제할 수 있습니다.

## 파일을 여는 방법

- 내용을 보려면 탐색기에서 DOCX를 마우스 오른쪽 버튼으로 누르고 **연결 프로그램 → Word**를 선택합니다.
- 코드 편집기로 DOCX를 열면 `PK` 등의 기호가 보일 수 있습니다. 이 화면은 Word 문서 화면이 아닙니다.
- 업로드 시험은 CleverSearch 관리자에서 **파일 선택**을 누르고 아래 경로의 DOCX를 선택합니다.

```text
D:\00.WORK\AI\프로젝트_설정_작업\내일_웹테스트_자료\02_신규업로드\수동검증_신규문서_20261001.docx
```
