# CleverSearch 자립 데모 — 실행 방법

작성일: 2026-04-30
작성자: 현승준
대상 산출물: `build_portable\CleverSearch-Demo.zip` (약 **2.16GB**)
포함 자산: 임베디드 Python 3.11 + JDK 17 + OpenSearch 2.18 + analysis-nori + ko-sroberta 모델 + 앱 소스

> **외부에 추가로 필요한 것은 PostgreSQL DB 서버 1대뿐**입니다. 그 외는 zip 한 개에 모두 들어 있습니다.

  CleverSearch-Demo.zip 압축 해제           PostgreSQL

## 1. 사전 준비 (DB 서버 측, 1회)

PostgreSQL 에 접속해 다음을 한 번만 만들어 둡니다.

```sql
CREATE DATABASE cleversearch;
CREATE USER cleversearch WITH PASSWORD '<강한 비밀번호>';
GRANT ALL PRIVILEGES ON DATABASE cleversearch TO cleversearch;

\c cleversearch
CREATE SCHEMA cleversearch_dev AUTHORIZATION cleversearch;
```

확인 사항
- 데모 PC → DB 서버 **5432 포트 방화벽 열림**
- DB 서버 `pg_hba.conf` 가 데모 PC IP 를 허용
- 운영 DB 라면 별도 데모용 DB/계정 신설 권장

## 4. `.env` 수정 (필수)

`D:\CleverSearch-Demo\.env` 를 메모장으로 열고 DB 접속정보만 수정합니다. 나머지 항목은 기본값 그대로 둬도 됩니다.

```env
# 외부 PostgreSQL — ★ 환경에 맞게 수정
DB_TYPE=postgres
DB_HOST=192.168.x.x
DB_PORT=5432
DB_NAME=cleversearch
DB_USER=cleversearch
DB_PASSWORD=<DB 비밀번호>
DB_SCHEMA=cleversearch_dev

# 시크릿 (32자 이상 권장. 시연만이라면 그대로도 가능)
JWT_SECRET=demo-please-change-this-to-strong-32-char-secret
CREDENTIAL_SECRET=demo-credential-secret-please-change-32+

# OpenSearch — 동봉본 사용. 변경 불필요.
OPENSEARCH_URL=http://localhost:9200
OS_ADMIN=admin
OS_PASSWORD=admin
OPENSEARCH_USE_SSL=false
OPENSEARCH_VERIFY_CERTS=false
```

> 팁: 시크릿은 PowerShell 한 줄로 안전한 값 생성 가능
> ```powershell
> [Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
> ```

## 5. 기동 — `start.bat` 더블클릭

**`D:\CleverSearch-Demo\start.bat` 를 더블클릭**하면 다음이 자동 수행됩니다.

```
1) 자체서명 인증서 자동 생성 (cert\demo.crt / demo.key)
   - PC hostname / 로컬 IP 가 SAN 에 자동 포함
2) OpenSearch 백그라운드 기동 (별도 콘솔 창)
3) OpenSearch 부팅 대기 (최대 90초)
4) DB 마이그레이션 (alembic upgrade head)
5) uvicorn HTTPS 기동 (포트 8000)
6) 기본 브라우저 자동 열기 → https://localhost:8000/admin
```

진행 메시지 예시:
```
[STEP] 자체서명 인증서 생성
[STEP] OpenSearch 시작
[STEP] OpenSearch 부팅 대기 (최대 90초)
[STEP] DB 마이그레이션 (alembic upgrade head)
[STEP] HTTPS 모드 기동 — https://localhost:8000/admin
```

### 첫 로그인
| 계정 | 비밀번호 | 권한 |
|---|---|---|
| admin    | admin123!     | admin    |
| operator | operator123!  | operator |
| viewer   | viewer123!    | viewer   |

> 보안 정책상 첫 로그인 후 **비밀번호 강제 변경** 플래그가 활성됩니다. 변경 API:
> ```
> POST /api/v1/common/auth/password
> { "current_password": "admin123!", "new_password": "Admin#NewPw1!" }
> ```
> (UI 미연결 — Swagger 또는 curl 로 호출)

### 브라우저 경고 ("안전하지 않음")
자체서명 인증서이기 때문에 정상적으로 발생합니다.
- 시연용: "고급 → 진행" 클릭하면 됩니다
- 깨끗하게 하려면: 별도 도구 [tools/cert_gen/dist/CleverSearchCertGen.exe](../tools/cert_gen/dist/CleverSearchCertGen.exe) 로 로컬 CA 만들고 PC 신뢰 등록 가능 (mkcert 흉내)

## 6. 종료 — `stop.bat` 더블클릭

**`stop.bat`** 더블클릭 시:
- 8000 포트 점유 프로세스(uvicorn) 종료
- OpenSearch 윈도우/프로세스 종료

> ⚠ stop.bat 은 **모든 java.exe 를 종료**합니다. 다른 Java 앱이 떠 있다면 같이 죽으니 stop.bat 의 java 종료 부분을 주석 처리하거나 작업 관리자에서 OpenSearch 프로세스만 골라 종료하세요.

## 8. 트러블슈팅

| 증상 | 원인 / 조치 |
|---|---|
| `[ERROR] alembic 마이그레이션 실패` | `.env` 의 DB 접속정보 오타 / DB 서버 미기동 / 방화벽 / 사용자 권한 |
| OpenSearch 부팅 대기 타임아웃 | `logs\opensearch.log` 확인. 메모리 부족 또는 9200 포트 점유 |
| 8000 포트 충돌 | 기존 uvicorn 종료 또는 start.bat 의 `--port` 변경 |
| 브라우저 "안전하지 않음" | 자체서명이라 정상. "고급 → 진행" 또는 별도 인증서 생성기로 신뢰 등록 |
| `nori` 분석 오류 | analysis-nori 플러그인 설치 실패 가능. `opensearch\bin\opensearch-plugin install analysis-nori` 수동 실행 |
| 모델 다운로드 시도 (인터넷 차단) | `models\hf_cache\` 안에 `models--jhgan--ko-sroberta-multitask` 가 있는지 확인. 빌드 시 사전 캐시 처리되었으므로 정상이면 인터넷 불필요 |
| Windows Defender 가 차단 | java/OpenSearch 의 별도 콘솔 실행을 한 번 허용 |
| symlink 경고 (HuggingFace) | Windows 개발자 모드 미활성화 시 뜨는 정상 경고 — 동작에는 영향 없음 |
| `[ERROR] 임베디드 Python 이 없습니다` | 압축 해제 실패 또는 `runtime\python311\` 폴더 누락 — 다시 압축 해제 |

### 로그 위치
- OpenSearch: `D:\CleverSearch-Demo\logs\opensearch.log`
- uvicorn: 콘솔 창 (start.bat 가 띄운 창) — 닫으면 서버 종료

## 9. 보안 안내 (반드시 읽어주세요)

이 자립 데모는 **시연/평가용**이며 다음 보안 완화가 적용된 상태입니다:

| 항목 | 데모 설정 | 운영 적용 시 |
|---|---|---|
| OpenSearch security 플러그인 | **비활성** (`plugins.security.disabled: true`) | 활성 + admin 비번 강화 + TLS |
| MFA | OFF (`MFA_REQUIRED_FOR_ADMIN=false`) | admin 강제 ON |
| HTTPS | 자체서명 | 사내 CA 또는 공인 CA |
| API 문서 노출 | ON (`ENABLE_API_DOCS=true`) | OFF |
| JWT/CRED SECRET | 데모 기본값 | 32자 이상 무작위 |

**격리망/사내망/단일 PC** 시연으로만 사용하세요. 외부 노출 시 OpenSearch 데이터가 무인증으로 노출됩니다.

운영 배포 시 [docs/보안점검_OWASP_국정원_조치내역_20260429_현승준.md](보안점검_OWASP_국정원_조치내역_20260429_현승준.md), [docs/보안점검_2차사이클_조치내역_20260429_현승준.md](보안점검_2차사이클_조치내역_20260429_현승준.md), [docs/보안점검_후속작업_백로그_20260429_현승준.md](보안점검_후속작업_백로그_20260429_현승준.md) 참고.

## 11. 빌드 (관리자용 — 데모 zip 을 다시 만들고 싶을 때)

빌드 환경(개발 PC, 인터넷 연결 + 약 10GB 디스크 여유):

```powershell
cd C:\02.Project\01.파이썬\01.WorkSpace\CleverSearch
PowerShell -ExecutionPolicy Bypass -File .\scripts\portable\build_portable.ps1
```

옵션:
| 인자 | 의미 |
|---|---|
| `-PythonVersion 3.11.9` | 임베디드 Python 버전 |
| `-OpenSearchVersion 2.18.0` | OpenSearch 버전 |
| `-JdkUrl ...` | JDK 17 zip URL 변경 |
| `-SkipModelDownload` | 모델 사전 캐시 생략 (zip ↓, 첫 실행 시 인터넷 필요) |
| `-SkipZip` | 압축 생략 — 펼친 폴더만 |

산출물: `build_portable\CleverSearch-Demo.zip`

빌드 시간: 첫 실행 30~60분 (다운로드 비중 큼). 재실행 시 `_tmp\` 캐시 활용으로 5~10분.

## 15. 문의 / 트러블슈팅 시 첨부 항목

문제 발생 시 다음을 첨부해 주시면 빠른 진단이 가능합니다:

1. `start.bat` 콘솔 출력 전체 (스크린샷 또는 텍스트)
2. `logs\opensearch.log` 마지막 100줄
3. `.env` (DB 비밀번호 마스킹 후)
4. 브라우저 DevTools 콘솔/Network 에러 (HTTP 응답 본 것 있으면)
5. `python --version` (시스템 Python 사용 시) — 본 빌드는 임베디드 Python 만 사용하므로 시스템 Python 무관
