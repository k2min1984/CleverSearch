관련 파일: [static/admin/smb.html](../static/admin/smb.html), [static/admin/dbsources.html](../static/admin/dbsources.html), [static/admin/index.html](../static/admin/index.html)

## 1. 작업 배경 (증상)

### 1.1 SMB / DB 색인 카드 UI

- 카드 우측 상단에 **닫기(X) 버튼**과 **활성/비활성 토글 스위치**가 같이 묶여 있어 시각적으로 혼잡
- 뱃지(SMB/CIFS, SSH/SFTP, PostgreSQL 등)가 어두운 회색 글씨로 죽어 보임 — 본래 채도 짙은 배경 위 흰 글씨여야 함
- 카드 안 5개 액션 버튼(접속 테스트 / 동기화 / 워커 색인 / 수정 / 이력) 디자인이 다른 메뉴 버튼과 다르게 컬러 사각형 → 디자인 일관성 깨짐

### 1.2 "+ 신규 등록" 버튼 동작 안 됨

- 액션바의 `+ 신규 등록` 버튼이 클릭해도 모달이 열리지 않거나 시각적으로 흐려져 인지 자체가 어려움

### 1.3 근본 원인

[index.html](../static/admin/index.html) 의 두 가지 전역 처리가 카드 페이지를 의도와 다르게 변형하고 있음:

| 위치 | 동작 | 부작용 |
|---|---|---|
| `normalizeTabUi(container)` ([index.html:1455](../static/admin/index.html)) | 탭 안 모든 button 에 `btn-unified` + `btn-soft`(또는 preset) 클래스를 강제 추가 | 카드 안 컬러 버튼이 흰색 캡슐형으로 변형되며 전체 디자인이 깨짐 |
| 다크→라이트 어댑터 CSS ([index.html:255-260](../static/admin/index.html)) | `#tabContent .text-white { color: #334155 !important; }` | 채도 짙은 배경 위 `text-white` 뱃지가 어두운 회색으로 강제 변환 — "흰 글씨"가 사라짐 |

### 1.4 해결 방향 (사용자 추가 지시 반영)

1. **카드 위치 재배치**: 좌상단=ID 정보, 우상단=닫기(X), 본문 뱃지 옆=활성 토글
2. **카드 안 액션 버튼은 다른 메뉴 버튼 디자인을 그대로 따름** — 컬러 클래스 모두 제거하고 normalizeTabUi 의 자동 디자인 통일에 맡김
3. **뱃지는 채도 짙은 배경 + 흰 글씨 유지** — 색상 어댑터 보강 셀렉터 + 인라인 `style="color:#fff"` 다중 방어
4. **신규등록 버튼**도 다른 탭과 동일한 자동 디자인 — `data-skip-normalize` 옵트아웃 해제

## 3. 새 카드 레이아웃

### 3.1 시각화

```
+------------------------------------------+
| ID: 12                              [X]   |  ← 좌상단=ID, 우상단=닫기
|                                            |
|  📁  소스이름                              |
|      [SMB/CIFS]  [● 활성 토글]             |  ← 본문 뱃지 옆에 활성 토글
|                                            |
|  공유 경로 / 포트 / 계정 / 도메인 (그리드) |
|  최근 동기화                                |
|                                            |
|  [접속테스트][동기화][워커색인][수정][이력]|  ← 다른 메뉴와 동일한 자동 통일 디자인
+------------------------------------------+
```

### 3.2 좌상단 ID 마크업

```html
<div class="absolute top-3 left-3 z-10 text-xs text-gray-500 font-mono select-none">
   ID: ${safeId}
</div>
```

### 3.3 우상단 닫기 마크업

```html
<button type="button"
        class="absolute top-3 right-3 w-7 h-7 rounded-full bg-gray-100
               hover:bg-red-100 text-gray-400 hover:text-red-500
               flex items-center justify-center transition-colors
               btn-smb-delete z-10 text-sm"
        data-id="${safeId}" title="삭제">
   <svg ...>X</svg>
</button>
```

### 3.4 본문 토글 배치

```html
<div class="flex items-center gap-2 mt-1 flex-wrap">
   ${typeBadge}     <!-- SMB/CIFS 뱃지 -->
   ${toggleSwitch}  <!-- 활성/비활성 토글 -->
</div>
```

### 3.5 카드 액션 버튼 (다른 메뉴와 통일)

```html
<button type="button" class="text-xs btn-smb-test"      data-id="...">접속 테스트</button>
<button type="button" class="text-xs btn-smb-sync"      data-id="...">동기화</button>
<button type="button" class="text-xs btn-smb-enqueue"   data-id="...">워커 색인</button>
<button type="button" class="text-xs btn-smb-edit"      data-id="...">수정</button>
<button type="button" class="text-xs btn-smb-hist"      data-idx="...">이력</button>
```

→ `bg-teal-600`, `bg-emerald-600` 등 모두 제거. `btn-smb-*` 식별 클래스만 유지.
→ normalizeTabUi 가 텍스트 기반으로 `btn-unified` + 적절한 preset(`btn-soft`/`btn-success` 등)을 자동 적용.
→ 결과: 다른 탭(스케줄러·SSL·사전 등)의 메뉴 버튼과 **동일한 캡슐형 흰색 그라데이션 디자인**으로 통일.

## 4. 새 프로세스 흐름 (탭 진입 → 카드 렌더 → 클릭)

```
[admin 진입]
  ↓ initializeSession() OK
  ↓ switchTab("smb" or "dbsources")
  ↓ container.innerHTML = <탭 HTML>          ← +신규등록 버튼 노드 생성
  ↓ <script> 노드 replace + 실행             ← addEventListener 등록
  ↓ normalizeTabUi(container)
      └─ 모든 button 에 자동으로 btn-unified + preset 적용
         (SMB/DB 카드의 모든 버튼이 다른 메뉴 버튼과 같은 디자인으로 통일)
  ↓ if (viewer) { admin-write 버튼 disable }
  ↓ tabInitMap[tabName]() = loadSmbSources() / loadDbSources()
  ↓ populateSmbList → renderSmbCards
      └─ 카드 HTML 생성 (좌상단 ID / 우상단 X / 본문 뱃지+토글 / 액션 버튼 5개)
  ↓ 사용자가 [+ 신규 등록] 클릭
  ↓ 등록된 click handler 호출 → clearSmbForm() + openSmbModal(false)
  ↓ smbModal.classList.remove("hidden") → 모달 표시
```

## 5. 기능 적용 이유

### 5.1 왜 ID 가 좌상단인가
- 토글이 시각적 강조 요소이므로 **본문 뱃지 옆**(맥락 있는 자리)에 두는 게 자연스러움
- ID 는 식별·디버깅용 정보이므로 본문 흐름에 섞이기보다 **좌상단 코너**에 잠잠히 두는 게 깔끔
- 닫기(X)는 마지막 액션 성격이므로 우상단(시선 끝나는 자리)이 관습적

### 5.2 왜 카드 액션 버튼의 컬러 클래스를 모두 제거했는가
- normalizeTabUi 는 "버튼은 모두 통일된 디자인" 이라는 전역 규칙으로, **거기에 컬러 버튼만 따로 두면 일관성 붕괴**
- 다른 탭은 모두 자동 디자인을 받아들이고 있어서 SMB/DB 카드만 다르게 보였던 게 사용자 위화감의 원인
- 컬러 클래스 제거 + normalizeTabUi 자동 처리로 **하나의 디자인 시스템에 합류**

### 5.3 왜 뱃지에는 `style="color:#fff"` 를 유지했는가
- 뱃지는 "타입 표시" 라는 정보 라벨로, 채도 짙은 배경 + 흰 글자가 의미 전달에 효과적
- 어댑터의 흰색 보존 보강 셀렉터에 추가 + 인라인 스타일로 이중 방어 → 어떤 우선순위 충돌에도 흰색 유지
- 액션 버튼과 달리 **뱃지는 클릭 가능한 컨트롤이 아니라 정보 표지**이므로 디자인 통일 대상에서 분리 가능

### 5.4 왜 normalizeTabUi 의 `data-skip-normalize` 옵트아웃은 남겨두는가
- 향후 카드형 탭에서 "이 버튼만은 컬러로 강조" 가 필요한 경우 다시 사용 가능
- 현재 SMB/DB 카드에서는 사용 안 하지만, 메커니즘 자체는 존재하는 것이 영향 0 (사용 안 하면 작동도 안 함)

### 5.5 왜 +신규등록이 동작 안 했었나 (재검증)
- 핸들러 등록은 정상이지만 **이전 컬러 클래스 + normalizeTabUi 의 흰색 그라데이션이 충돌** → "파란 배경 위 어두운 글씨" 같은 시각 깨짐
- 컬러 클래스를 제거하니 normalizeTabUi 가 깔끔하게 자동 디자인을 입혀서 시각·동작 모두 정상화

### 5.6 왜 `pt-10` 으로 카드 상단 여백을 두는가
- 좌상단 ID + 우상단 X 가 카드 상단 12~16px 영역을 차지
- 본문 첫 줄(아이콘·이름·뱃지)이 그 위에 겹치지 않도록 padding-top 으로 안전 여백 확보
- 기존 `p-5` (20px) 만으로는 부족하여 `pt-10` (40px) 적용

## 6. 영향 범위

| 영역 | 영향 |
|---|---|
| SMB 색인 탭 카드 / 액션바 / 모달 | 위치 재배치 + 다른 메뉴와 동일 디자인 통일 + 신규등록 정상 동작 |
| DB 색인 탭 카드 / 액션바 / 모달 | 동일 |
| 다른 탭 (대시보드, 스케줄러, SSL 등) | 변화 없음 — 기존 normalizeTabUi 자동 처리 그대로 |
| 색상 어댑터 | 채도 짙은 배경 위 흰 텍스트 보존 보강 셀렉터 추가 (뱃지 보호용). 어댑터의 다른 효과는 유지 |
| 백엔드 / DB / API | 변경 없음 |
| 권한 (viewer / admin) | viewer 일 때 admin-write disable 로직 그대로 작동 |

## 8. 테스트 시나리오

1. **카드 외관**
   - SMB 색인 탭 진입 → 카드 좌상단 `ID: 12`, 우상단 X 표시
   - 본문에 뱃지(`SMB/CIFS`) 옆에 활성 토글이 자연스럽게 배치
   - DB 색인 탭도 동일
2. **뱃지 색상**
   - SMB/CIFS, SSH/SFTP, PostgreSQL, MySQL, Oracle, MSSQL, SQLite 뱃지가 흰 글씨 + 채도 짙은 배경
3. **카드 액션 버튼**
   - 5개 버튼이 모두 다른 탭(스케줄러·SSL 등)과 동일한 캡슐형 흰색 그라데이션 디자인
   - 텍스트(`접속 테스트`·`동기화`·`수정`·`이력`)에 따라 자동으로 `btn-success`/`btn-soft` 등 preset 적용
4. **신규 등록 버튼**
   - 액션바 `+ 신규 등록` 버튼이 다른 메뉴 버튼과 동일 디자인으로 표시
   - 클릭 시 모달이 정상으로 열림
   - SMB 모달에서 새 소스 등록 후 카드 목록 갱신
   - DB 모달도 동일하게 동작
5. **활성 토글**
   - 카드 본문 토글 클릭 → 즉시 활성/비활성 전환되며 색상 변경
6. **viewer 권한**
   - viewer 로 로그인 → admin-write 버튼 disable + 흐릿하게 표시 (기존 정책 유지)
7. **다른 탭 회귀**
   - 대시보드, 스케줄러, SSL 등 진입 — 디자인 변화 없음

## 10. 후속 작업 제안 (선택)

- 다른 카드형 탭(indexing/scheduler/volume)도 동일 위치 규칙(좌상단 ID, 우상단 닫기)으로 통일
- 카드 컴포넌트를 공통 CSS 클래스로 추출(예: `.cs-source-card`)해서 두 탭 간 중복 줄이기
- normalizeTabUi 의 텍스트 기반 preset 분기에 `등록`, `이력`, `워커` 같은 키워드를 추가해 의미별 색감 다양화 가능
