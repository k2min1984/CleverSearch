# 프로젝트별 남은 사항 — 쉬운 설명

작성일: 2026-09-30

## 먼저 두 프로그램의 역할

- **CleverSearch**: 문서를 찾아주는 검색 프로그램. 도서관에서 원하는 책을 찾아주는 역할이다.
- **CLEVERCHAT**: 질문과 선택지를 받아 안내하는 상담 프로그램. 안내 데스크 역할이다.

현재 두 프로그램은 이 PC에 만든 DB로 실행하고 기능을 검증했다. 아래 목록은 각각 **회사 서비스 연결**, **아직 안 해본 규모의 시험**, **미지원 기능**, **다른 사람이 접속할 때의 설정**을 뜻한다.

## 1. 회사 DB·로그인·AI·메일 연결

이전 설명에서 여러 기능을 한 줄에 묶어 프로젝트 구분이 불명확했다. 실제 코드 기준으로 나누면 다음과 같다.

| 무엇인가 | 해당 프로젝트 | 쉬운 설명 | 현재 상태 |
|---|---|---|---|
| 프로그램이 쓰는 회사 DB | **둘 다** | 프로그램의 기록을 넣어두는 회사 보관함이다. Search는 문서 정보·검색 기록, Chat은 상담 내용·관리 설정 등을 저장한다. | 이 PC의 DB는 구성·구동·검증 완료. 실제 회사 운영 DB를 대상으로 한 연결 검증은 하지 않았다. |
| 회사 자료 수집용 DB·공유 폴더 | **CleverSearch** | 회사 서랍에 있는 문서를 가져와 검색할 수 있게 만드는 기능이다. | 실제 회사 자료 저장소에서 가져오는 작업은 미검증. 운영 대상·계정·접근 권한 확인이 필요하다. |
| 회사 통합 로그인(SSO) | **CLEVERCHAT** | 회사 사이트에 한 번 로그인하면 챗봇에서도 나를 알아보게 하는 기능이다. | 로컬 계정 로그인 검증 완료. 실제 회사 로그인 시스템과 연결하는 검증은 미완료. |
| 생성형 AI 답변(LLM/vLLM) | **CLEVERCHAT** | AI가 검색한 자료를 읽고 답변 문장을 만들어주는 기능이다. | 현재 상담·검색 답변은 동작한다. 실제 AI 서버 연결은 미구성·미검증. AI 서버 주소·모델·필요시 인증 정보가 필요하다. |
| 메일 알림 | **CLEVERCHAT** | 문제가 생겼을 때 관리자에게 이메일로 알려주는 기능이다. | 메일 전송 코드가 있다. 실제 발송 서버 연결·수신 확인은 하지 않았다. 메일 서버·발신 주소·수신 대상 등이 필요하다. |

SSO·생성형 AI·메일은 이번 코드 확인에서 **CLEVERCHAT의 연동 기능**으로 확인했다. CleverSearch의 검색용 AI 모델(문장의 뜻을 숫자로 바꾸는 모델)은 이미 실행·검증한 기능이며, 여기서 말한 미연결 LLM과 용도가 다르다.

‘연결 정보가 없다’는 이전 표현은 부정확하게 뭉뚱그린 설명이었다. 정확히는 **실제 운영에 사용할 대상과 접근 방법을 확정해서 검증하지 않았다**는 뜻이다. Search 소스에는 기존 원격 환경 설정이 있었고, 이번 작업은 별도 로컬 환경을 선택해 검증했다.

## 2. 많은 자료·많은 사용자·오래 켜두기 — 둘 다

한두 사람이 쓰는 것과 아주 많은 사람이 동시에 쓰는 것은 다르다. 며칠 동안 켜두었을 때도 계속 잘 작동하는지 확인해야 한다.

- **CleverSearch**: 문서가 크게 늘어도 검색이 느려지거나 업로드가 멈추지 않는지 확인한다.
- **CLEVERCHAT**: 여러 사람이 동시에 질문하거나 대화 기록이 많이 쌓여도 답변이 잘 오는지 확인한다.
- **현재 상태**: 기능·시나리오 테스트는 통과했다. 대용량/장시간 성능 시험은 아직 하지 않았다. 실제로 느리거나 멈춘다는 문제가 발견됐다는 뜻은 아니다.

## 3. 사진 안의 글자 읽기(OCR) — CLEVERCHAT 크롤러

안내문을 글자로 올린 경우에는 글을 바로 가져올 수 있다. 안내문을 사진 한 장으로 올렸다면, 사진 속 글자를 읽는 별도 기능이 필요하다. 이것을 OCR이라고 한다.

- **대상**: CLEVERCHAT이 웹사이트를 돌아다니며 내용을 가져오는 크롤러.
- **현재 상태**: 사진으로만 된 본문의 글자는 읽지 못하고 제목만 남을 수 있다. 이 기능은 미지원이다.
- **사용할 때의 영향**: 안내 내용이 사진 안에만 있으면 그 내용을 상담 답변에 충분히 활용할 수 없다.
- **CleverSearch**: 업로드한 한국어 이미지 파일의 OCR은 설치·검증했다. Chat의 웹 이미지 수집과는 별도 경로다.

## 4. 다른 사람이 안전하게 접속하도록 준비 — 둘 다

현재 주소의 `127.0.0.1`은 ‘지금 이 컴퓨터’를 뜻한다. 다른 사람의 컴퓨터에서 같은 주소를 입력하면 그 사람 자신의 컴퓨터를 가리킨다.

다른 직원이나 외부 사람이 접속하도록 서비스하려면 다음을 준비해야 한다.

- **접속 주소/접속 경로**: 사람들이 찾아올 수 있는 회사 서버 주소나 도메인.
- **운영 계정과 권한**: 들어와도 되는 사람과 사용할 수 있는 기능을 정한다.
- **HTTPS**: 로그인 정보와 대화를 주고받을 때 내용을 암호화한다. 편지를 봉투에 넣어 보내는 것과 비슷하다.
- **현재 상태**: 두 프로그램 모두 localhost HTTP 개발 환경으로 검증했다. 외부 공개 배포는 하지 않았다. Search의 관리자 추가 인증(MFA) 필수 옵션은 이 로컬 환경에서만 꺼져 있다.

## 한눈에 정리

| 프로젝트 | 정상 검증한 범위 | 남은 사항 |
|---|---|---|
| **CleverSearch** | 로컬 DB/검색 엔진, 파일 업로드·검색·한국어 이미지 OCR·관리자 기능 등 검증 시나리오 | 실제 회사 자료 연결, 대용량·장시간 시험, 운영 공개 설정 |
| **CLEVERCHAT** | 로컬 DB, 로그인, 시나리오 상담·검색·피드백·관리자 기능, 외부 크롤링 테스트 | 실제 회사 DB/SSO/AI/메일 연결, 웹 이미지 본문 OCR, 대용량·장시간 시험, 운영 공개 설정 |

이 문서는 남은 사항을 설명하기 위한 문서 수정이다. 이번 설명 과정에서 서버 설정이나 프로그램 동작을 추가로 변경하지 않았다.
