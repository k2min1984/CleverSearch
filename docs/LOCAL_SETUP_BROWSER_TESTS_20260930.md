# 실제 브라우저 검증 결과

2026-09-30, Codex in-app browser에서 localhost 서버를 직접 조작했다.

## CleverSearch

| 항목 | 결과 |
|---|---|
| 검색어 입력/오타 교정 | 계휙서 → 계획서, 결과 2건 표시 |
| 문서 카드 본문 미리보기 | 클릭하여 표시, `<mark>` 문자열 노출 발견 후 수정 및 재확인 |
| 관리자 로그인 | 성공, 대시보드의 색인 문서 5건 확인 |
| 검색 운영 | 인기검색어, 검색로그, 최근검색어, 실패검색어, 검색품질 탭 렌더링 |
| 콘텐츠 운영 | 문서리스트, 파일업로드, 사전관리 탭 렌더링 |
| 수집/색인 | SMB, DB, 통합색인이력, 파일감시, 네트워크, 스케줄러 탭 렌더링 |
| 시스템/보안 | 볼륨, SSL, 초기화 탭 렌더링. 기존 데이터 삭제 버튼은 실행하지 않음 |
| 가중치 저장 및 복원 | 제목 구문 20→25 저장 확인 후 기본값20 복원 확인 |
| 검색 품질 평가 | 연구개발계획서/보안/AI개발/통합검색/운영지침: 5/5 통과 |
| 콘솔 | 확인 시 오류 0건 |

외부 SMB/SSH/DB가 연결되지 않은 상태의 관리 화면 렌더링 검사다. 실제 원격 수집 성공으로 해석하지 않는다. 초기화 시나리오의 깨끗한 시작 조건은 새 격리 로컬 DB/인덱스로 충족했다.

## CLEVERCHAT

| 항목 | 결과 |
|---|---|
| 관리자 로그인 | localadmin 로그인 성공 |
| 신규 설치 시나리오 등록 화면 | 정상 렌더링. 최초 분류가 비어 있어 로컬 검증 분류/예제를 API로 생성 |
| 상담 주제 | 로컬 설치 확인 안내 표시 |
| 대화 시작 | 확인할 항목과 실행 주소 보기 선택지 표시 |
| 선택지 | 8000/8080 실행 주소 답변과 검색 화면 링크 표시 |
| 종료 | 안내 종료 선택 시 완료 상태와 종료 메시지 표시 |
| 콘솔 | 확인 시 오류 0건 |

뒤로가기, 피드백, 세션 소유권, 검색 후보에서 상담 전환, 관리자 메뉴·CSRF 검사는 별도 실제 HTTP 보고서에 있다.

## 외부 원문 확인

한전 전자공고 첫 게시물 ‘주식명의개서 정지공고’(2026-08-27)의 본문은 alt가 없는 이미지로 구성됨을 브라우저 DOM과 화면에서 확인했다. 제목만 추출된 결과는 현재 크롤러의 sparse fallback 정책과 일치한다. Java 크롤러의 이미지 OCR은 미지원이다.
