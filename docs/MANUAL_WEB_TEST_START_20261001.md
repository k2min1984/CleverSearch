## 6. 결과를 적는 법

| 결과 | 뜻 |
|---|---|
| 통과 | 적힌 클릭을 직접 해 보고, 정상 결과까지 확인함 |
| 실패 | 준비 조건을 갖췄는데 정상 결과와 다름 |
| 보류 | 회사 서버·계정·파일·추가 사용자가 없어 아직 실행할 수 없음. 이유를 적음 |
| 미실행 | 아직 클릭하지 않음 |

“화면이 열렸다”와 “저장·검색·상담까지 된다”는 각각 따로 확인한다. 자료가 없는 목록의 `0건`은 정상일 수 있지만, 자료를 만든 뒤에도 없으면 실패다. 숫자는 테스트하면서 늘어나므로 문서에 나온 기준 건수를 무조건 고정해서 비교하지 않는다.

오류가 나면 아래 5가지를 남긴다.

1. 시나리오 번호: 예 `CS-14`, `CC-28`.
2. 주소와 누른 버튼.
3. 입력한 값(비밀번호 제외).
4. 화면에 실제로 나온 문장과 캡처.
5. 발생 시각과 새로고침 후에도 같은지.

표시 시간이 PC 시간과 약 9시간 다르면 기존 UTC 표시 영향인지 구분한다. 기록 조회 기간은 우선 **최근 7일** 또는 시험일 전후를 포함하도록 잡는다. 시간 표시 차이도 개선 의견으로 기록할 수 있다.

## 7. 이번 전체 테스트의 범위

두 프로젝트의 사용자 화면과 현재 관리자 메뉴를 모두 포함했다. 메뉴 안에서 조회·추가·수정·저장·필터·거절·복원을 나눴다. 다음은 준비가 필요한 별도 항목이다.

| 대상 | 당장 확인할 수 있는 것 | 준비 후 확인할 것 |
|---|---|---|
| CleverSearch 회사 DB·SMB·SSH | 화면, 필수 입력, 로컬 폴더 접속 | 회사 자료 저장소 접속 및 실제 수집 |
| CLEVERCHAT 시스템 설정 | 다섯 탭, 현재 값, 저장·복원 | 사용자 설명상 동우가 담당할 후속 작업 범위 및 실제 SSO·AI 연동 |
| CLEVERCHAT AI 연결 | 미설정 표시와 미설정 오류 안내 | 동우 AI의 실제 주소·모델·인증 방식·답변 |
| CLEVERCHAT 메일 | 알림 화면과 비활성 채널 설정 | SMTP 설정, 시험 수신함, 실제 수신 |
| CLEVERCHAT 크롤링 | 등록·조회 화면 | 허용된 공개 시험 URL과 외부 통신. 웹 이미지 본문 OCR은 현재 미지원 |
| 둘 다 | 한 PC의 브라우저 기능·짧은 반복 사용 | 대규모 동시 접속, 장시간 부하, 실제 회사 DB·공개 HTTPS 운영 |

연결 정보가 없어서 `보류`인 것을 `통과`로 바꾸지 않는다. AI가 연결되지 않은 현재 상태에서 미설정 안내가 나오는 것은 정상이며, 그 결과로 AI 답변 기능을 통과 처리하지 않는다.
