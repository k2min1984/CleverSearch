# CleverSearch 로고 클릭 시 연결 오류 — 수정 기록

날짜: 2026-09-30 / 대상: **CleverSearch 사용자 검색 화면**

## 사용자가 겪은 문제

검색 화면의 CleverSearch 로고를 누르면 `https://127.0.0.1:8000/`으로 이동하며 ‘이 사이트에 연결할 수 없습니다’가 나왔다.

## 원인

현재 로컬 검색 서버는 **HTTP**로 실행 중이다. HTTP 요청은 200 정상 응답이었다. 그런데 검색 화면 두 파일의 `goHome()` 함수는 주소를 `https://127.0.0.1:8000/`으로 고정하고 HTTPS만 허용하도록 검사했다.

서버가 꺼진 문제가 아니라 **홈 버튼이 현재 서버와 다른 접속 방식의 주소로 안내한 오류**다. 앞선 기능 점검에 로고 클릭이 빠져 발견하지 못했다.

## 수정

- `C:\02.Project\01.파이썬\01.WorkSpace\CleverSearch\static\index.html`
- `C:\02.Project\01.파이썬\01.WorkSpace\CleverSearch\static\user\index.html`

두 파일에서 고정 주소와 해당 주소 전용 검사를 제거하고 `window.location.assign('/')`로 이동한다. 현재 접속한 서버·포트·HTTP/HTTPS 방식을 유지하면서 홈으로 간다. 로컬 HTTP로 접속하면 HTTP를 유지하고 HTTPS로 배포된 곳에서는 HTTPS를 유지하는 방식이다. 실제 운영 HTTPS 배포 시험을 새로 수행한 것은 아니다.

기존 검색 상태·스크롤 저장값을 지우고 이전 검색이 홈에서 다시 복원되지 않게 하는 처리는 유지했다. 서버의 HTTPS 정책이나 인증 설정을 끄지 않았다.

## 문서와 데이터 영향

- 내일의 CleverSearch **CS-01**에 로고 마우스 클릭·Enter·HTTP 홈 복귀·검색창 초기화를 추가했다.
- 결과표의 CS-01 요약도 갱신했다. 내일 사용자의 결과는 계속 `미실행`으로 두었다. 이번 개발자 확인 결과는 위 표에 별도 기록했다.
- 전체 수동 시나리오 수 158개는 그대로다.
- 기능 확인을 위한 두 번의 정상 검색으로 검색 로그/최근 검색어가 추가될 수 있다. 문서·계정·DB 구조는 변경하지 않았다.
- CLEVERCHAT 소스는 변경하지 않았다.
