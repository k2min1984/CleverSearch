이 PC에서 CleverSearch가 현재 사용하는 DB의 **등록된 문서 제목·본문·파일명**을 읽도록 설정했다. 계정, 비밀번호, 접속 기록 테이블은 수집 대상으로 넣지 않았다. 회사의 별도 업무 DB 접속을 검증한 결과는 아니다.

## 확인 결과

1. 등록 전 DB 소스 0건 확인. 저장 후 DB 소스 1건, ID 1 확인.
2. 저장된 소스의 접속 테스트 API: `success / DB 연결 성공`.
3. 지정한 네 컬럼을 실제 SELECT하여 문서 6건을 읽을 수 있음을 확인. 문서 본문은 검사 로그에 출력하지 않음.
4. 저장값을 API로 다시 읽어 제목·테이블·컬럼·PK·증분 기준·활성 상태 일치 확인.
5. 실제 브라우저 DB 색인 화면: 총 1건, 한글 이름 정상, PostgreSQL, 활성, `cursor=id (int) / pk=id`, 미동기화 표시 확인. 해당 검증 탭의 콘솔 오류 0건.
6. 스케줄러는 작업 전후 중지 상태 유지. 동기화 작업을 접수하지 않았고 검색 문서 추가/삭제를 수행하지 않음.

## 화면에서 확인하는 순서

1. 관리자 **DB 색인**을 다시 누른다. 이미 같은 화면이면 F5로 새로고침한다.
2. `CleverSearch_현재DB_문서데이터` 카드와 **총 1건**이 보여야 한다.
3. 카드의 **접속 테스트**를 누르면 **DB 연결 성공** 안내가 나와야 한다.
4. 입력 항목을 보려면 카드 오른쪽 위 연필 모양 **수정**을 누른다. 접속 URL에는 비밀번호가 포함될 수 있으므로 공유 기록에 그대로 복사하지 않는다.

‘미동기화’는 DB 연결 실패라는 뜻이 아니다. **연결 정보만 저장했고, DB의 내용을 검색창에 새로 가져오는 동기화는 아직 하지 않았다는 뜻**이다.

## 범위 및 확인된 주의점

- 이번 작업은 연결 정보 등록·저장값·접속·원본 행 조회·카드 표시까지 확인했다. DB 동기화 완료/검색 결과/수정 행 재색인까지 통과했다고 기록하지 않는다.
- 선택한 원본은 이미 업로드로 검색되는 문서다. 처음 DB 동기화를 실행하면 같은 내용이 DB 소스의 별도 검색 문서로 추가될 수 있다.
- 증분 기준 `id`는 새 문서 추가를 찾는다. 기존 행의 본문만 고친 경우 ID가 그대로이므로 해당 변경 확인에는 전체 모드가 필요하다.
- 화면의 기본 볼륨 문구는 `cleversearch-docs`로 고정되어 있다. 저장값 null의 실제 목적지는 현재 환경의 `cleversearch-workstation-docs`이다. 이번 요청에서 화면 소스는 수정하지 않았다.
- 코드 검토 중 DB 처리기 `app/services/db_job_processor.py::_record_history`가 SMB 이력 테이블을 사용하며 통합 `IndexingHistory`에는 직접 기록하지 않는 점을 확인했다. DB 동기화의 이력 표시·소스 ID 충돌 여부는 별도 수정/실행 검증이 필요한 항목으로 남긴다. 이번에는 해당 경로를 실행하지 않았다.

## 작업 중 이슈와 처리

- 서버가 `select_columns`를 쉼표 뒤 공백이 있는 문자열로 정규화해서 첫 검증 스크립트의 단순 문자열 비교가 실패했다. 저장 및 접속 테스트는 이미 성공한 상태였다.
- 검증 스크립트를 컬럼별 비교로 보정하고, 같은 이름의 소스가 있으면 재등록하지 않게 처리했다. 재검증 통과. 중복 소스 없음.
- 재검증 JSON의 `source_count_before=1`은 첫 등록 이후 재검증 시점 값이다. 최초 읽기에서는 0건이었다.
- 변경 파일: 작업용 `27-register-current-db-source.py`, 본 기록, 작업일지, 승인내역. 앱 소스 변경과 서버 재시작 없음.
- 증거: `db-source-registration.json`(비밀번호·접속 URL 제외).

## 권한 기록

사용자의 명시적 등록 요청 및 기존 작업 위임에 따라 수행했다. 프로젝트 Python으로 로컬 DB 조회와 API 저장/검증을 실행하는 `require_escalated` 요청은 자동 검토 후 허용되었다. 사용자 대신 승인 버튼을 눌렀다는 뜻은 아니다. 상세 이력은 `승인내역_2026-09-30.md`의 A-027에 기록한다.
