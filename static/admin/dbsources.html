🗄️ DB 색인이란? 외부 데이터베이스의 뷰(VIEW) 또는 테이블에서 텍스트 데이터를 추출해 OpenSearch 에 색인합니다.
• 임의 SELECT 입력은 받지 않습니다. 보안상 뷰/테이블 이름과 텍스트 컬럼 목록만 입력하면 백엔드가 안전한 SELECT 를 자동 조립합니다.
• JOIN·WHERE 등 복잡한 조건이 필요하면 DBA 에게 전용 뷰 생성을 요청해 주세요. 권한도 해당 뷰에 한정해 부여하는 것이 안전합니다.
• 접속 테스트: DB 타입·접속 URL 로 실제 접속 가능 여부를 사전에 확인합니다.
• 동기화: 백그라운드 큐(SyncJob) 등록 방식. cursor_column 기반 증분 색인 + 중단 시 재개되며 다른 기능에 부하를 주지 않습니다.
• 이력: 해당 DB 소스의 색인 이력을 카드에서 펼쳐봅니다.
